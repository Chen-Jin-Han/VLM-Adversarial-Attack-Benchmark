# Official M-Attack-V2 author release (epsilon 16/255)

These 100 PNGs are unchanged copies of the `epsilon_16` split published at:
https://huggingface.co/datasets/MBZUAI-LLM/M-Attack-V2-Adversarial-Samples

Paper: https://arxiv.org/abs/2602.17645

Official implementation: https://github.com/VILA-Lab/M-Attack-V2

The original `metadata.csv` is included. `provenance.json` pins the dataset revision and implementation commit and records each image's SHA-256, size, and dimensions. All 100 hashes match the upstream Git LFS object hashes. The upstream dataset card declares the MIT license.

This is the authors' released 100-image set, not a newly trained 1,000-image set. Its target correspondence has not been verified against the canonical FOA 1,000-pair manifest, so it is not counted among the complete matched benchmark sets. No evaluations or scores from the removed revised V1 pipeline are reused here. The epsilon-8 split is excluded.
