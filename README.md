# VLM Adversarial Attack Benchmark

This repository collects adversarial images generated by representative attacks on vision-language models (VLMs), together with paper references and links to the corresponding official implementations.

The repository is intended for reproducible academic research on adversarial transferability and robustness. It does not contain attack-success evaluations or model-generated responses.

## Repository layout

```text
.
├── Adversarial-Images/  # Complete sets of 1,000 generated images
├── Papers/              # Papers and citation information
├── Projects/            # Official implementations as Git submodules
├── Metadata/            # Configuration and dataset manifests
└── README.md
```

## Important comparability note

The image sets do not all represent the same attack objective.

- FOA-Attack, MPC-Attack, M-Attack, M-Attack-v2, and AttackVLM use paired source and target images.
- The `X-Transfer-UAP-*` results use a universal adversarial perturbation and are not one-to-one source-target attacks.
- The `X-Transfer-Paired-*` results are a benchmark adaptation initialized from the released X-Transfer UAP and then optimized against the corresponding target-image feature for each numeric source-target pair. This is not the official X-Transfer UAP protocol.
- SSA-CWA is an untargeted ensemble attack in this benchmark configuration.
- AnyAttack uses its pretrained attack model and does not consume the paired target images.

Consequently, the `X-Transfer-UAP-*`, SSA-CWA, and AnyAttack outputs must not be reported as pairwise target-image attacks. Only the explicitly named `X-Transfer-Paired-*` adaptation uses paired target images.

`M-Attack-v2-Eps16` is a revised benchmark execution pipeline based on the same M-Attack paper and official project; it is not a separate published method.

## Perturbation settings

Where a method's original perturbation budget differs from 16/255, this repository keeps the original and standardized versions in separate directories. Standardized variants support controlled comparisons, while original variants preserve the published configuration.

No similarity-threshold filtering is applied to select the images in this repository.

## Papers and official projects

The `Papers/` directory contains the corresponding papers and a reference index. The `Projects/` directory uses Git submodules that point to the official upstream repositories. Clone recursively to retrieve them:

```bash
git clone --recursive https://github.com/Chen-Jin-Han/VLM-Adversarial-Attack-Benchmark.git
```

For an existing clone:

```bash
git submodule update --init --recursive
```

## Large-file storage

Adversarial images are tracked with Git LFS. Install Git LFS before cloning if the full-resolution images are required:

```bash
git lfs install
git lfs pull
```
