# VLM Adversarial Attack Benchmark

This repository collects adversarial images generated by representative attacks on vision-language models (VLMs), together with paper references and links to the corresponding official implementations.

The repository is intended for reproducible academic research on adversarial transferability and robustness. It does not contain attack-success evaluations or model-generated responses.

The active benchmark contains **six paired attack sets**, each with **1,000 images** and an **L-inf budget of 16/255**, using the original FOA numeric source-target correspondence. FOA's GPT-4o descriptions and scores are available separately in the [OSV-Attack baseline directory](https://github.com/Chen-Jin-Han/OSV-Attack/tree/main/Baselines/FOA-Attack-Eps16).

Every published directory contains exactly 1,000 readable 224-by-224 images named `0.png` through `999.png`, for **6,000 adversarial images** in total. Sets with budgets other than 16/255 or without paired target images have been removed from the active benchmark.

The current configurations are recorded in [attack-configurations.yaml](Metadata/attack-configurations.yaml). The [cleanup manifest](Metadata/benchmark-cleanup.json) lists the removed directories and reasons.

## Important comparability note

All active sets use paired source and target images, but their implementations retain the following distinctions:

- FOA-Attack, MPC-Attack, M-Attack, M-Attack-v2, and AttackVLM use paired source and target images.
- M-Attack-v2 is a revised benchmark execution pipeline based on M-Attack, rather than a separate published method.
- `X-Transfer-Paired-Eps16` is a benchmark adaptation initialized from the released X-Transfer UAP and then optimized for 300 steps against the corresponding target-image feature using OpenAI CLIP ViT-B/32. This is not the official X-Transfer universal-perturbation protocol.

The original FOA numeric pairing is preserved in [foa-source-target-pairs.json](Metadata/foa-source-target-pairs.json), including the source and target SHA-256 hashes for each image ID. No target images were replaced during cleanup. See [generation-notes.md](Metadata/generation-notes.md) for protocol details.

## Perturbation settings

Every active set is configured with an L-inf budget of 16/255. All 6,000 retained images were checked against their published Git LFS SHA-256 hashes and file sizes, decoded successfully, and verified to have a maximum absolute RGB pixel difference no greater than 16 from the corresponding canonical FOA source. Per-image results are recorded in [benchmark-audit.json](Metadata/benchmark-audit.json).

These checks verify image integrity and source-relative pixel budgets. Target pairing is declared by the benchmark generation configurations; the image audit does not independently recover the optimization target from adversarial pixels.

No similarity-threshold filtering is applied to select the images in this repository.

## Papers and official projects

The `Papers/` directory contains the corresponding papers and a reference index. The `Projects/` directory uses Git submodules that point to the official upstream repositories. Clone recursively to retrieve them:

```bash
git clone --recursive https://github.com/Chen-Jin-Han/VLM-Adversarial-Attack-Benchmark.git
```

For an existing clone:

```bash
git submodule update --init --recursive
```

## Large-file storage

Adversarial images are tracked with Git LFS. Install Git LFS before cloning if the full-resolution images are required:

```bash
git lfs install
git lfs pull
```

## Work in progress

Additional sets must use the same original FOA source-target correspondence, an L-inf budget of 16/255, and a paired target-image attack protocol. Only complete, verified 1,000-image sets will be published; partial and unpaired outputs are excluded.
